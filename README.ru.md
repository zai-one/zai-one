Запросить отчёт по трафику, изучить поисковый спрос, поработать с Telegram или передать задачу разработки — всё из совместимого MCP-клиента. ## От репозитория до первого результата

1. **Выберите сервис.** В русском и английском README есть сценарии, а в инструкции установки — требования к аккаунту или CLI.
2. **Настройте доступ локально.** Не передавайте секреты в чат или GitHub Issues. Ограничения доступа и платные операции описаны в самом проекте.
3. **Подключите MCP-клиент.** Используйте пример конфигурации, проверьте настройку и повторите первый запрос из README.

Используйте релиз с фиксированной версией, если он есть. Код и тесты находятся в репозитории проекта; там же ищите опубликованные заметки к релизам и сведения о сторонних компонентах. Интеграции работают самостоятельно: подписка на услуги агентства ZAI.ONE не нужна. Доступ к провайдеру, его API-лимиты и использование моделей оплачиваются и настраиваются вами.
